Semana 2 · Álgebra de Boole y formas canónicas

Unidad 1 · R1: diseña e implementa circuitos combinacionales básicos con técnicas de diseño clásico. Lunes: teoría y alarma · Martes: APE 02 en Logisim · Miércoles: taller de simplificación.

Esta semana aprendí a ir del enunciado a la tabla de verdad, de ahí a la forma canónica y por último a un circuito simplificado.

1. Un circuito y una expresión son lo mismo

Retomé la APE 01: el circuito formado por una AND de A y B, una NOT de C y una OR que une ambas salidas.

SalidaValor de la expresión

El circuito se escribe Y = A·B + C'. La precedencia es NOT → AND → OR.

Respondí las preguntas del inicio con la tabla de la Semana 1: si A = 1, B = 0, C = 0 entonces A·B = 0 y C' = 1, así que Y = 1. Si A = 1, B = 1, C = 1 entonces A·B = 1 y por lo tanto Y = 1 también.

2. Del enunciado a la especificación

La frase «la sirena suena cuando se activan dos sensores» se puede leer de dos maneras:

Lectura 1: exactamente dos

Filas 011, 101, 110, es decir F = Σm(3, 5, 6). Con los tres sensores activos no suena.

Lectura 2: al menos dos

Filas 011, 101, 110 y 111, es decir F = Σm(3, 5, 6, 7). Es la que pide el cliente.

Lo importante es fijar la lectura antes de diseñar.

3. Postulados de Huntington y dualidad

El álgebra de Boole trabaja sobre el conjunto {0, 1} con tres operaciones: + (OR), · (AND) y ' (NOT).

PostuladoForma ORForma AND (dual)
IdentidadX + 0 = XX · 1 = X
ComplementoX + X' = 1X · X' = 0
ConmutativaX + Y = Y + XXY = YX
DistributivaX(Y + Z) = XY + XZX + YZ = (X + Y)(X + Z)

Dualidad: si intercambio + por · y 0 por 1 (sin complementar variables), la identidad sigue siendo válida. La distributiva de la derecha es la que más me sorprendió porque no existe en el álgebra común.

Demostración de la distributiva dual

Quiero probar A + BC = (A + B)(A + C) partiendo del lado derecho:

(A + B)(A + C)punto de partida

= A + AC + AB + BCidempotencia: AA = A
= A(1 + C + B) + BCfactor común A
= A + BCelemento nulo: 1 + … = 1

5. Leyes de De Morgan

Rompo la barra y cambio el operador: (AB)' = A' + B' y (A + B)' = A'B'. Generaliza a n variables, por ejemplo (A + B + C)' = A'B'C'. En el circuito, una NAND equivale a una OR con las entradas negadas, y una NOR equivale a una AND con las entradas negadas.

En parejas · 5 minutos

Apliquen De Morgan

1. (A·B·C)'. Se rompe la barra y cambia el operador: A' + B' + C'.

2. (A + B'C)'. Primero De Morgan sobre la suma: A' · (B'C)'. Luego sobre el producto interno, (B'C)' = B + C', así que queda A'(B + C'). Distribuyo: A'B + A'C'.

3. (A'B + C)'. De Morgan sobre la suma: (A'B)' · C'. Luego (A'B)' = A + B', entonces queda (A + B')C'. Distribuyo: AC' + B'C'.

Verificación con una fila. Para el ejercicio 2 tomo A = 0, B = 1, C = 0. Lado izquierdo: B'C = 0·0 = 0, A + 0 = 0, y su complemento es 1. Lado derecho: A'B + A'C' = 1·1 + 1·1 = 1. Coinciden.

6. Minitérminos y maxitérminos

Un minitérmino mᵢ es un producto donde la variable en 1 aparece sin complemento y la que está en 0 aparece complementada. Un maxitérmino Mᵢ es una suma donde la variable en 0 aparece sin complemento y la que está en 1 aparece complementada. Se cumple Mᵢ = (mᵢ)'. Todavía no hay una F: son las 8 piezas posibles y cada función elige cuáles usa.

7. Formas canónicas: SOP y POS

Uso como ejemplo la sirena (al menos 2 sensores):

iABCFmᵢ de la filaMᵢ de la fila

SOP: miro los 1

Por cada fila con F = 1 tomo su minitérmino y los uno con OR.

F = Σm(3, 5, 6, 7)
= A'BC + AB'C + ABC' + ABC

POS: miro los 0

Por cada fila con F = 0 tomo su maxitérmino y los uno con AND.

F = ΠM(0, 1, 2, 4)
= (A+B+C)(A+B+C')(A+B'+C)(A'+B+C)

Es la misma función con dos descripciones. SOP dice «F vale 1 si la entrada es la combinación 3, o la 5, o la 6, o la 7». POS dice «F vale 1 si la entrada no es la 0, y no es la 1, y no es la 2, y no es la 4». Entre ambas listas están todas las filas (0 a 7): los índices de ΠM son los que faltan en Σm.

¿SOP o POS?

  • Pocos 1 en la tabla: SOP lleva menos términos.
  • Pocos 0 en la tabla: POS lleva menos términos.
  • Solo hay NAND disponibles: SOP → NAND-NAND (7400).
  • Solo hay NOR disponibles: POS → NOR-NOR (7402).

El criterio final es el costo: compuertas, circuitos integrados y niveles lógicos.

8. Resolución guiada: alarma de 3 sensores

Enunciado. Una bodega tiene tres sensores: puerta (A), ventana (B) y movimiento (C). Para evitar falsas alarmas, la sirena F suena si al menos dos sensores se activan. La tabla es la de la sección anterior.

De la canónica a la simplificada. Parto de F = A'BC + AB'C + ABC' + ABC. Por idempotencia, ABC se puede escribir tres veces (ABC = ABC + ABC + ABC), un término sirve para tres pares:

  • A'BC + ABC = BC(A' + A) = BC
  • AB'C + ABC = AC(B' + B) = AC
  • ABC' + ABC = AB(C' + C) = AB

Resultado: F = AB + AC + BC. En POS: (A + B)(A + C)(B + C).

Costo de cada versión. La canónica necesita 7404 + 2×7411 + 7432 = 4 CI. La simplificada necesita 7408 + 7432 = 2 CI. Lo que simplifico en papel lo ahorro en hardware.

9. Simplificar con álgebra: procedimiento

  1. Pares adyacentes: XY + XY' = X.
  2. Duplicar un término si hace falta: X = X + X.
  3. Absorción: X + XY = X.
  4. Absorción del complemento: X + X'Y = X + Y.
  5. Consenso: XY + X'Z + YZ = XY + X'Z.

No hay un algoritmo que garantice el mínimo, y por eso la Semana 3 llegan los mapas de Karnaugh. Dos expresiones son equivalentes si y solo si tienen la misma tabla de verdad, así que siempre compruebo con una fila.

Ejemplo de la clase del miércoles

Simplificar F = A + A'B + AB'C

ExpresiónJustificación
F = A + A'B + AB'Cexpresión original
= (A + B) + AB'Cabsorción del complemento: A + A'B = A + B
= A + AB'C + Bconmutativa
= A + Babsorción: A + A(B'C) = A

Pasé de 3 términos (5 literales) a una sola OR de 2 entradas. Comprobación con A = 0, B = 0, C = 1: la expresión original da 0 + 0 + 0 = 0 y la simplificada A + B da 0. Coinciden.

Aviso de cinturón (Grupo 8)

Enunciado. El aviso suena si el motor está encendido (E) y el cinturón no está puesto o la puerta está abierta (P). Entregar: tabla, Σm y ΠM, SOP canónica, versión simplificada, y recuento de compuertas y CI.

Variables y especificación

  • E = 1 si el motor está encendido.
  • C = 1 si el cinturón está puesto (por eso «cinturón no puesto» es C').
  • P = 1 si la puerta está abierta.
  • Leí el enunciado así: el motor tiene que estar encendido, y además falla el cinturón o hay puerta abierta. O sea F = E·(C' + P). Con el motor apagado nunca suena.

Σm y ΠM

F = Σm(4, 5, 7) y F = ΠM(0, 1, 2, 3, 6). Los índices de las dos listas son complementarios: (4, 5, 7) y (0, 1, 2, 3, 6) completan las 8 filas.

SOP canónica

F = EC'P' + EC'P + ECP, con m4 = EC'P', m5 = EC'P y m7 = ECP.

Simplificación

  • EC'P' + EC'P = EC'(P' + P) = EC'
  • EC'P + ECP = EP(C' + C) = EP (los dos términos comparten m5; uso idempotencia)
  • Resultado: F = EC' + EP, que equivale a E(C' + P).

También lo comprobé con el mapa de la Semana 3: los grupos EC' (m4, m5) y EP (m5, m7) dan la SOP mínima, y al agrupar los ceros obtengo la POS E(C' + P).

Individual, al cierre del lunes

Ticket de salida

1. Aplicar De Morgan a (A' + BC)'. Primero la barra sobre la suma: (A')' · (BC)' = A·(BC)'. Luego la del producto: (BC)' = B' + C'. Queda A(B' + C'), y distribuyendo, AB' + AC'. Compruebo con A = 1, B = 0, C = 0: el original da (0 + 0)' = 1 y el resultado da 1 + 1 = 1.

2. m4 corresponde a la fila 100, así que A = 1 y B = C = 0: m4 = AB'C'. M4 es la suma con la variable en 0 sin complemento y la que está en 1 complementada: M4 = A' + B + C. Se cumple M4 = (m4)'.

Resumen de la semana

  • Circuito = expresión: lo que simplifico en papel lo ahorro en hardware.
  • La tabla manda: dos expresiones son equivalentes si y solo si tienen la misma tabla.
  • Canónica: siempre se puede (Σm con las filas en 1, ΠM con las filas en 0) y es única.
  • Simplificar es elegir por costo: menos compuertas, CI y niveles. El álgebra no garantiza el mínimo.
